# 2027 江苏 × 浙江省考招录图谱

本项目沿用 [2027 国考招录观测台](../guokao-data-film/reference/2027国考_招录观测台_交互修复完整版.html) 的“人数与职位数分离、可交互切换、来源可追溯”方法，将分析维度改为省考的 **省份 / 地市 / 机关层级 / 考试类别**。独立离线 HTML，双击 `index.html` 即可使用，无网络依赖。

> **状态：V1 汇总级分析，不是已经逐岗位审计的机关排行榜。**  
> **统计截点：2026-11-10；招录年度：2027。**

## 数据定义与总量

| 省份 | 公告计划人数 | 当前已发布职位数 | 当前职位表对应人数 | 公告与在表差额 |
| --- | ---: | ---: | ---: | ---: |
| 江苏 | 8,149 | 5,725 | 8,149 | 0 |
| 浙江 | 4,511 | 3,298 | 4,223 | 288 |

- **职位数**：一个有效职位表记录对应一个职位，不等于招录人数。
- **招录人数**：职位行内计划人数之和，不能用职位数代替。
- **浙江差额 288**：4,511 − 4,223；公告总额包含后续山区海岛县专项招录预留计划。该差额不进入当前地市、机构或职位筛选，亦不推断为已经发布的 288 个岗位；具体构成以后续官方职位表为准。
- **江苏地市口径**：监狱戒毒系统的职位在“按工作地”汇总时计入对应地市；在“按来源文件”展示时又单列 166 岗 / 237 人。这两张表是不同的分类维度，禁止相互叠加。
- **江苏第三方层级 / 类别统计**：各自分别闭合至 5,725 岗、8,149 人，但尚未以全部官方原表逐行审计，不能作为官方机关系统划分。

## 数据核验

V1 开发时执行以下加总门禁：

1. 江苏 13 市 + 省级机关，合计 **5,725 岗 / 8,149 人**。
2. 浙江 11 市 + 省属单位，合计 **3,298 岗 / 4,223 人**。
3. 江苏来源表、层级表、考试类别表均独立合计 **5,725 岗 / 8,149 人**。
4. 统计页面内置同样的 JavaScript 断言，若任一口径不闭合会抛错并停止展示。

这仅意味着**已录入聚合数字在算术上闭合**，不等于对官方原始职位表逐岗位、逐字段完成审计。

## 下一版升级：真正的“招录机关 → 具体局 / 系统 → 职位”

本 V1 不虚构公务员系统级别的精确分布。要实现国考观测台同级别的机关、岗位剖析，需解析官方原始 Excel 并逐行标准化：

- 保存每条记录的 `source_file`、`source_sheet`、`original_row`、`province`、`city`、`agency_original`、`agency_normalized`、`institution_system`、`job_code`、`job_title`、`headcount`、`exam_category`、`major_original`、`degree_original`、`eligibility_notes`。
- 系统分类先作人工校准样本，再以可追踪规则分为党政机关、纪检监察、组织人事、公安、法院、检察院、司法行政/监狱、行政执法、市场监管、乡镇街道、其他机关及参公等；避免按机关名称关键字过度归并。
- 机关跨地市计数需定义唯一岗位标识：建议 `省份 + 来源表 + 招录机关 + 职位代码`，遇到编码重复再加入行号。
- 必须分别校验 **职位数、人数、城市、考试类别、系统分类**；未解析项列为“待分类”并保留原文，不允许静默吞掉或凭空填补。
- 针对浙江专项预留创建独立 `announced_not_listed` 计划表，后续公告发布后再进入公开岗位明细，不能现在补造职位。
- 报名竞争指数需等待真实、注明日期的报名/审核合格统计，不用第三方页面里空白或默认“0”充当真实报名数据。
- 最终在 UI 中新增系统旭日图、机构排名、机关×城市矩阵、学历专业筛选与岗位明细侧栏，并附来源行级回溯。

## 页面功能

省份切换、人数/职位/每岗人数切换、地市排序与搜索、点击查看城市详情、江苏机关层级与 A/B/C 分类对照、CSV 导出、来源直链；响应式、无 CDN、离线可用。

本项目仅为招录计划结构研究，不替代政府招考公告、职位资格审查及报名系统。
