## 一句话主旨

**把 2027 国考 35,691 个计划招录名额拍成一部从全国结构走向一个具体岗位、最终回到人的数据电影：数字要真实，变化要能解释，情绪要有克制。**

当前英文片名/视觉副题：**SEATS / 35,691 · A Data Film**。原工作名称为《国考宇宙》，仅在早期创意与历史提交中作为检索别名保留。影片不是网页功能演示、招生广告或纯视觉 Demo；**内容洞察、电影化 Motion Design、可复现的程序化工程**是三条同等重要的主线。

## 想回答的核心问题

- **宏观：** 2027 年到底招多少人、哪些系统和层级承担主要招录、看似庞大的数字如何分布？
- **结构：** 为什么“招录岗位数、计划名额、过审人数、进面分数、专业要求”不能混成一个数字？税务名额占比和非税务重排说明什么？
- **具体：** 一个专业代码怎样在真实岗位原文中被提及？放大到单个岗位时，部门、职位名称、学历、备注等限制是什么？
- **人的尺度：** 数据背后有考生的选择、准备与不确定性；“冷思考”只把有据的社会背景与明确标记的作者观点呈现在画面上，不把相关性讲成因果。

**希望观众带走的感受：** 全国结构很大，但每个名额最终落到一个具体岗位与一个人的选择；影片既让人看懂，也让人愿意回看画面。既不渲染恐慌，也不为任何报考行为作出保证。

## 现有 V2 的叙事骨架

V2 已把原始的 80–90 秒概念扩展为约 **5 分 27 秒**的完整作品：**序幕 → 越来越挤 → 谁在招 → 一年巨变 → 门槛与画像 → 分数 → 冷思考 → 一个座位 → 尾声**。

- **序幕 / 越来越挤：** 从“人”进入数据，用过审与计划数的口径差揭示宏观张力，再落到 2027 名额点阵。
- **谁在招 / 一年巨变：** 在真实部门和层级上重排同一组数据；税务集中度与跨年变化必须标明是否同级来源。
- **门槛与画像 / 分数：** 解释学历、政治面貌、基层年限、面试入围线，严格切换岗位与名额的计数单位；2026 分数不可冒充 2027。
- **冷思考：** 毕业生规模、青年就业、财政背景是**不同来源的二手研究和讨论**，不能据此推定具体岗位待遇或行业因果关系。
- **一个座位 / 尾声：** 从专业代码的**原文字面提及**放大到有复合岗位 ID 和原表行号的单个名额，完成由全国到个体的情感收束。

**导演原则：** 视觉的运动要帮助理解数据关系；一条镜头的高亮、数量、图例、字幕必须来自同一个可重算状态。要有呼吸、克制与审美统一，而非机械轮播所有图表。V2 是当前实作基线，不要求未来每个版本照搬所有幕。

## 项目范围

**本项目做：** 国考招录结构的数据电影、可信解释与可复现的 Motion Design；可在后续扩展短版、9:16、分系统/专业的**有来源**短片。

**本项目不做：** 个人报考资格自动裁定、招录机关咨询代理、依据热度推荐报考岗位、未经证实的 2027 进面预测；也不涵盖另一个仓库的真题爬取/题库建设。新选题具有独立目标、受众、数据/交付物时，应在 `projects/<new-slug>/` 重新立项并分配新编号。
