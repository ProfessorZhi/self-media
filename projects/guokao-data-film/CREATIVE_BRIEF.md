# 创意 Brief · 席位之间（历史工作名：《国考宇宙》）

## 1. 核心诉求

制作一部可作为「AI Coding × Data Visualization × Motion Design」技术力和审美力代表作的知识可视化影片。即使观众并不关心国考，也应被画面尺度、图形连续变形、镜头语言与节奏吸引；而关心国考的人应获取清晰、可核验的招录结构认识。

影片不是介绍网页功能的产品演示，而是**以同一套数据为演员**：粒子可以组成新的图、保持身份、响应选择、排列重组。信息传播是内容、空间运动也是叙事。

希望模型具备导演的取舍能力，而不是按清单穷举所有可能的图表。复杂度服务于某个数据问题和镜头设计。

## 2. 创作母题

早期工作片名曾是「**国考宇宙 / CIVIL SERVICE · THE DATA UNIVERSE**」；已于 V2.1 品牌修订改为 **《席位之间》｜35,691**。本文件保留原始创意作为历史参考，现行片名见 [BRANDING.md](BRANDING.md)。

一条从**微观名额 → 全国结构 → 发现集中度 → 排除税务重构 → 个体系统 → 关联网络 → 重新收拢**的视觉路径。

概念升级：用户提出「选择一个专业代码，各类相关图表逐层亮起来」。不要实现成简陋的 simultanous blink。设计为 **Query → Signal Propagation → Focus → Reallocation → Reveal**：

- 输入/选择状态成立时，少数核心节点先响应；
- 高亮沿真实数据关系向外传播，而不是随意飞线；
- 非相关数据降低对比，而非完全消失，保留全国参照系；
- 镜头追随一条可解释路径：单个代码词元 → 标签与地区 → 聚合统计卡；获得逐岗位证据后再下钻具体岗位；
- 最终图表/计数/标签更新为同一筛选结果，镜头停留足够长便于理解。

**当前数据边界：** 新增聚合已含地区×系统和单词元的交叉统计。M1优先制作真实税务筛选。专业数据存在学历目录碰撞和TK截断，只可做带说明的词元探索；完整专业与具体岗位镜头需回到原文重建。

## 4. 候选 90 秒节奏（可以被更优秀的导演方案替代）

| 时段 | 叙事 | 运动设想 |
| --- | --- | --- |
| 00–10s | 数据觉醒 | 黑场的一点逐步扩展为 35,691 个名额点，镜头推拉切换尺度 |
| 10–23s | 结构形成 | 点按同源省份×标签单元聚类，再切换地区/系统视角；28类另作独立场景 |
| 23–37s | 集中度的反转 | 税务 67.3% 呈现；隐藏税务后，其余名额重新分配视觉空间 |
| 37–51s | 连续图形变形 | 旭日图 → 矩形树图 → 横向系统排名，追踪同一类别 |
| 51–70s | 跨图状态联动的高潮 | 同源系统筛选点亮地区与聚合卡；专业词元可另作有审计说明的探索段 |
| 70–82s | 多尺度分析 | 排名、帕累托、散点、细节数字和解释性标签交替形成分析高潮 |
| 82–90s | 收束与片尾 | 图形归一，呈现项目身份、片名、数据免责声明 |

影片不是八段平均速度的 UI 演示；在强运动镜头与静态阅读镜头之间建立呼吸节奏。选择核心有识别度的 3–5 个英雄镜头，胜过每秒切一个华丽图表。

## 5. 视觉语言

方向：产品发布影片式精度 + 高端 Motion Design + 数据新闻信息密度 + 适量电影空间感。

参考 HTML 色彩：深橄榄黑 `#121812`、珊瑚橙 `#f18e6b`、鼠尾草绿 `#a4c9ad`、灰蓝 `#abb8d5`；这些是出发点而非永久束缚。

- **布局：** 大尺度数字、严格网格、足够留白；镜头用平移、推进、景深变化解释宏观和微观。
- **形态：** 点阵、环、面积、条、散点可由同一数据实体连续映射；注意视觉对应关系。
- **光影：** 低亮背景，选择性高亮，少量高质感 Bloom/体积效果；绝不滥用霓虹。
- **Typography：** 中文数字清晰，字符间距、字体字重、行高、缩放时抗锯齿有明确规范。
- **交互隐喻：** 选中像「信号触发」「节点传播」，而不是到处同时闪白光。
- **音效：** 低频冲击、细颗粒群集、材质切换、锁定提示音要与真实节奏匹配；配乐授权合法可溯源。
- **避免：** PPT 切页、伪科幻 UI 套壳、无意义曲线、错误面积感知、不能解释的地理热图、过密文案。

## 6. 技术呈现重点

Remotion + React + TypeScript 为主。SVG / Canvas / WebGL / Three.js / React Three Fiber / shader 等按画质和可控性择优使用，而不是为了宣传工具而堆技术。

设计应刻意处理以下挑战：

1. 万级名额点阵在 1080p/4K 下的可读性、性能和稳定渲染。
2. 有同源交叉证据的图表保持稳定视觉索引；缺联合表的维度重建场景，不伪造岗位身份。
3. 筛选状态能同步驱动图形、数字、标签、镜头焦点与亮度。
4. 相机运动帮助观众理解位置关系，而不是制造眩晕。
5. 所有画面依赖 Remotion 帧索引与确定性函数；不要使用未经同步的浏览器随机计时器。
6. 字体、视频长度、音效、帧率及复现环境在项目中可验证。

## 7. 取材与传播策略

现有数据适合构成一支高质量主片：全国规模与形态演化、税务主导结构、非税务重新分布、单系统探索、每岗招录和集中度。

当前可增加《同一个0809，为何是两个专业方向？》这类数据认知短片。真实专业系列应从原文、学历和目录版本重建后选样；旧词元的计数差不能解释为某专业实际机会的多少。

优先输出能静音看懂的 B 站/抖音等社媒素材。首条 16:9 主片通过后再做 9:16 重构，不直接机械裁切。

## 8. 好作品的判断标准

- 视觉：三个静帧也像正式电影设计图，镜头之间构图与颜色一致。
- 叙事：观众知道「现在看什么、为什么变化、数据代表什么」。
- 技术：不是视频编辑器里预渲染片段的拼接；真的有数据驱动的精确联动和程序化变形。
- 数据：所有真实数字从源数据计算、有免责声明、可回溯，不猜测和杜撰。
- 交付：可完整渲染、有源代码、可调参数、截图、排查过视觉与数据问题。

允许 Opus 以比此 Brief 更好的结构重新组织影片；需要保留的只有真实的数据约束和可验证的交付标准。
