更新：2026-10-18。本轮目标是交付充足、详实、可追溯的岗位及国考数据；创意与视频表达由 Opus 决定。

**本轮最重要的变化：2027 全国岗位表已与官方招考简章工作簿完成 19,426 岗全表逐格核验（27 字段、524,502 单元格、内容差异 0），不再是“仅官方子集 805 岗”。** 专业层新增两份研究生招生代码册与 2026 自设学科名册，并把“专业”“备注”两列分开索引、跨字段去重后重新统计覆盖。

**现在每个 2027 岗位都有完整专业原文和原始条件；显式代码已从“专业列”扩展到“专业+备注”两列；完整个人报考资格仍未自动判定。**

## 2. 每个岗位有什么

岗位主键示例：`2027:002000:100110001001`。年度、六位部门代码、十二位职位代码都参与主键；单独职位代码只有 7,178 个不同值，会发生碰撞。部门代码的前导零必须保留。

27 个原字段按原始中文列名保存（部门代码、部门名称、用人司局、机构性质、招考职位、职位属性、职位分布、职位简介、职位代码、机构层级、考试类别、招考人数、专业、学历、学位、政治面貌、基层工作最低年限、服务基层项目工作经历、是否在面试阶段组织专业能力测试、面试人员比例、工作地点、落户地点、备注、部门网站、咨询电话1—3）。所有原字段按字符串返回；空单元格、原文“无”“不限”“无限制”分别保存。

`annotations.source_csv_province`、`annotations.source_system_tag` 是第三方注释，来源与原文分开。31 个省级注释都与原工作地点前缀一致，但没有把它提升成完整地理编码认证。

## 4. 专业究竟统计到哪一步（本轮重点）

### 4.1 新旧口径对照

| 检查 | 旧层（专业列） | 新层（专业+备注，五目录） |

| 至少一个目录候选引用的岗位 | 18,176 | 18,655 |
| 没有任何目录候选引用的岗位 | 1,250 | 771 |
| 涉及计划名额 | — | 1,209 |

新增覆盖 479 岗，来源分开记账：

| 新增依据 | 岗位 |

| 研究生代码册带来的六位二级学科解析 | 147 |
| 新目录下的完整名称词项 | 194 |

“出现一个候选引用”不表示整条要求解析完毕，更不是可报资格。771 与 5,835 不是互斥分组。

### 4.2 备注列怎么取代码

备注列共 19,172 岗非空，直接套正则会得到电话号码和年份。本轮按上下文过滤：

| 过滤掉 | 次数 |
| --- | ---: |
| 年份（如 2027） | 9,915 |
| 7 位以上长数字（电话） | 1,864 |
| 区号 | 146 |
| 既无目录命中也无专业语境的形状 | 126 |

保留结果：1,069 岗备注含代码提及，366 岗的备注代码可解析到目录；67 岗备注出现精确目录名；706 岗两列都有代码。同一岗位同一代码只计一次，两列来源都保留（238 种代码两列都出现）。

### 4.3 代码形式与“不许合并”的规则

| 形式 | 处理 |
| --- | --- |
| `030100`、`050100` 等四位+`00` | 记为四位学科的招生写法，**不是新专业**（55 种） |
| `030101K`、`030108TK`、`0502100T` | 原样保留后缀与七位码 |
| `0814Z2` 等 Z 码 | 只解析四位前缀，标记为培养单位自设，不编造代码-名称对应 |
| `99J…`、`S…` | 同样标记为机构/自主审核层面代码 |
| 同一六位数在本科/研究生含义不同 | 不合并；按分句学历分别解析，不匹配时记为“越出本学历口径” |
| `会计学类` vs `会计学` | 不做模糊匹配，只有精确目录名才命中 |

### 4.4 代码-名称冲突（逐岗取证）

59 个岗位存在代码旁印刷名称与目录名称不一致的情况，冲突按类分开，不合成一个“错误数”：

| 冲突类型 | 条数 | 含义 |
| --- | ---: | --- |
| `cross_level_same_code` | 25 | 同一代码在另一学历层另有名称（如 080401 本科=材料科学与工程、研究生=精密仪器及机械） |
| `category_suffix_omitted` | 8 | 原文省略“类”字（如 0203 = 金融学类） |
| `content_conflict` | 67 | 名称属于另一个代码（如 `120202财务管理`，120202 实为企业管理） |

每条冲突都带 `field`、代码、跨度、目录名称、印刷名称与上下文原文，可逐岗回放。

### 4.5 排除项

600 个岗位的专业列含 `不含/除/不包括` 括号清单。这些名称**不计入覆盖**，只作为排除证据保留（`major_excluded_names`）。例如“经济金融类（不含统计、国际商务、资产评估…）”里的国际商务是排除项，不是可报专业。

### 4.6 残留清单

771 岗（1,209 人）在五份目录、两列文本中都没有精确命中，原因分布：

| 原因 | 岗位 |
| --- | ---: |
| 专业列无显式代码词元 | 764 |
| 两列都没有可机读代码 | 768 |
| 开放表述（相关/等专业/方向） | 492 |
| 否定或排除句 | 446 |
| 排除清单 | 444 |
| 只以“类”结尾、无精确目录节点 | 213 |
| 名称只存在于另一学历层 | 22 |
| 代码在已加载目录中仍无法解析 | 7 |

最大单一来源是人民银行系统的“经济金融类（不含统计、国际商务、资产评估、经济与贸易类、国际贸易等专业）”，420 岗、722 人。**人民银行没有公开发布独立的专业目录附件**：其 2027 公告只说“具体职位和资格条件请查看专题网站招考简章”。中国气象局的“气象类”88 岗同理。这两类不应靠模糊相似硬套教育部目录。

## 5. 反向查询

```bash
# 完整代码 → 真实岗位与计划人数
node scripts/query_major_evidence.mjs --code 030101K

# 精确目录名（可加学历过滤）
node scripts/query_major_evidence.mjs --name 世界经济 --education graduate

# 目录节点 → 岗位
node scripts/query_major_evidence.mjs --catalog moe-bachelor:2026:080901

# 单个岗位的全部证据
node scripts/query_major_evidence.mjs --position 2027:002000:100110001001

# 残留清单，可按原因与原文过滤
node scripts/query_major_evidence.mjs --residual --reason exclusion_list_present --text 经济金融类

# 汇总数字
node scripts/query_major_evidence.mjs --stats
```

查询结果都带 `resolution.status`（`resolved` / `ambiguous_level` / `outside_education_scope` / `institution_local_code` / `unresolved`）。`outside_education_scope` 表示该代码只存在于另一个学历层——**不是命中**。

旧的读取入口仍然有效：

```js
import {loadPositions} from './scripts/load_positions.mjs';
import {loadMajorData} from './scripts/load_majors.mjs';
const jobs = await loadPositions();
const majors = await loadMajorData();
const law = majors.findExplicitCode('030101K'); // 329 岗、399 人（仅专业列旧口径）
```

| 目录 | ID | 范围 | 来源 |

| 研究生 2022 | `moe-graduate:2022` | 14 门类 / 117 一级 / 67 专业学位类别 | 国务院学位委员会、教育部 PDF |
| 招生代码册 2023 | `moe-graduate-codebook:2023-admissions` | 785 节点，含 602 个六位二级学科 | 教育部高校学生司 2022-09 |
| 招生代码册 2024 | `moe-graduate-codebook:2024-admissions` | 791 节点，含 554 个六位二级学科 | 教学司〔2023〕11号 附件，2023-09 |

两份代码册是**招生口径**，不是学位授予目录：四位码不一定等于 2022 目录编号（例如 0270 统计学、0771—0783 的理学编号）。两版差异真实存在（64 个代码只在 2023 版、70 个只在 2024 版），逐版保存、不合并。

自设名册只有名称、没有代码：Z/J 码由培养单位自行编排，名册不公布对应关系，因此本轮**没有**把任何 Z 码映射成某个名称。

自设名册解析出 497 个单位，媒体口径为 496；两份官方附件中没有可合并的近重复名称，差异原样保留在 `institution_union_note`。

## 7. 其他国考数据的使用口径

历年职位表统计：2024 年 18,948 岗 / 39,561 人；2025 年 20,810 / 39,721；2026 年 20,714 / 38,119；2027 年 19,426 / 35,691。2027 取自官方工作簿；2024—2026 取第三方 CSV 原始字段，属于不同来源等级。

2026 首批最低面试分：20,227 岗来自公开名单镜像的**源表公布最低线列**，未用个人成绩求最小值；审计署 35 岗官网公布线与之一致；另有 487 个当年岗位未出现在首批名单，不填 0 分。全国政策合格线、逐岗入围线、实际面试成绩是三种不同口径。

备注的 15 类文字线索是**可复现的文字检索**，不是完成资格审核后的岗位数。

## 8. 核验强度与保留事项

```bash
node scripts/verify_position_data.mjs --write-report     # 192,487 条显式断言
python3 scripts/verify_major_evidence.py --write-report  # 新证据层不变量
python3 scripts/verify_official_national_table.py --workspace <inputs>  # 全表官方逐格
```

需要外部输入的重建：

```bash
python3 scripts/build_position_foundation.py --workspace <inputs> --mode positions
python3 scripts/build_major_catalogs_20261018.py --workspace <sources>   # 需 pypdf / pdfplumber
python3 scripts/build_major_evidence.py                                  # 只读库内数据
```

**当前还没有**：完整个人报考资格判断、机关自定义专业目录（人行“经济金融类”、气象“气象类”等）、2027 笔试后的入围分数、实时报名人数、可证明的上岸概率或待遇结论。

**仍未解决**：771 岗专业表述无法精确落到目录；职位代码单独不唯一（19,426 岗只有 7,178 个不同职位代码），必须用“年度+部门代码+职位代码”定位；`02法学、05文学、08工学、12管理学` 这类门类码与名称明显错配的 5 个岗位只做标记，不改原文。

保留缺失、约数、批次与来源，比补一个没有依据的数值更适合后续创作。现行/历史状态见 [DATASET_STATUS.json](data/DATASET_STATUS.json)。
