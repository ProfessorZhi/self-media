**中文片名：**《席位之间》  
**视觉签名：** `35,691`  
**英文辅助标题：** `SEATS / 35,691`  
**说明性副标题：** `2027 国家公务员招录数据电影`

**一句话介绍：**“35,691 个计划招录名额，穿过宏观结构，最终落到一张真实的岗位表和一个人的选择。”

这里的“席位”是一种影片叙事隐喻，**画面统计单位始终写为“计划招录名额”，不是已录取人数或已经被分配的座位**。影片围绕结构与选择，不是选岗建议、概率预测或公务员招聘服务。

## 程序兼容与版本

- **稳定项目路径**：`projects/guokao-data-film/`，不迁移原始岗位证据或数据分片。
- **稳定内部 Composition ID**：`GuokaoUniverse`，作为 API 标识保留以兼容 V1/V2 重渲染命令；它不是对外影片名字。
- **最新默认导出**：`out/between_seats_2027.mp4`（`npm run render`）；4K 手动命令使用 `out/between_seats_2027_4k.mp4`。历史 V1/V2 输出文件名仍按其固定提交还原。
- **V1/V2 原始提交不改写**。此轮片尾品牌名与末幕章节编号修订作为 **V2.1 候选**，只有在新的 MP4 重渲染和逐镜审校完成后才能标为发行版。
- **章节序号**：前六幕依序 01–06，`Act7Thinking.tsx` 为 06「冷思考」，`Act6OneSeat.tsx` 为 07「一个座位」。章节序号必须与 `ChapterRail.tsx` 的实际出现顺序一致。

## 内容表达与来源等级

- 用“岗位数 / 计划招录名额 / 过审人数 / 最低面试分数”这类精确单位，禁止混为一个“考公人数”。
- 视频的 11 个“系统”来自部门名称规则分组，**不是官方机构性质分类**。
- 专业代码“在专业栏出现”不等于完整的报考资格匹配；示例 030101K 的相关岗位不能直接当作该专业全部可报岗位。
- 《冷思考》中的财政、就业等材料独立记录二手来源，作者观点必须明确区别于官方统计。
- 不为了片名、封面或传播效果修改数值的含义；35,691 只指已核对版本的 2027 **计划招录名额**。

## 实际交付闸门

**本次命名修改是源码阶段，不是重新渲染完成。** 对外发布新的片尾标题之前，需在授权的 Dell A6000 环境重建数据、生成配乐、重新渲染 4K，逐帧检查片尾字样、章节序号、字幕可读性以及音画同步。GitHub 文档静态检查不替代视频成片验收。
