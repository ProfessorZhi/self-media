## 你的角色与作品标准

同时担任 Creative Director、Data Storyteller、Information Designer、Motion Designer 和 Remotion Technical Lead。

目标是用 **Remotion + React + TypeScript** 创作令人印象深刻、逻辑严密、设计水平一流的 80–90 秒中文数据影片。

不是录屏，不是 PPT，不是图表清单演示，不是借助无意义 neon 特效掩盖叙事不足的 UI Demo。我要看到程序化动画能提供的、普通视频剪辑难以自然实现的视觉表达：万级数据点形成结构、图表形态连续迁移、统一过滤状态跨图传播、电影化的微观—宏观镜头语言与准确的数字排版。

你有权推翻参考分镜，只要新的电影表达更具创造性、更清晰，也更可信。应该把艺术决策建立在取材逻辑和美学判断上，而不是为了炫技堆积工具。

## 工作流程

**Step 1｜理解与提案**
- 读取现有数据与审计，核对版本、量纲和交叉单元；HTML用于视觉参考与独立28类口径，不另抄演出数字。
- 自主比较至少两个不同的影片创意方向，选出你真正认为最好的一个（简洁陈述选择理由），提出全片情绪曲线、主导视觉语言、3–5 个英雄镜头。
- 不要因为参考文档提到旭日图和点阵就只会复刻它们，欢迎更优的信息图形语法。

**Step 2｜创建可运行动画**
- 在本项目子目录里独立初始化 Remotion 工程。
- 参考当前官方文档与 Remotion Skills，合理使用 SVG/Canvas/WebGL/Three.js，技术栈按实际需要选择。
- 数据与时间线分离：每个镜头的数字和图形由其标明的可审计数据源驱动，全部运动由帧号确定。
- 先实现一个最震撼、但可理解、可稳定渲染的英雄镜头作为风格质量基准，然后扩展整片。
- 字体、颜色、文案、数据标签、镜头位置、入场与转场统一设计；音效与画面同步，确保静音可理解。

**Step 3｜真实运行与验收**
- 检查依赖安装、预览、截图、任意帧预览与完整输出。
- 先实际渲染12–15秒、1920×1080 / 30fps英雄镜头，检查起止及中间关键帧、计数和文字。M1通过后再扩展完整主片。
- 如果性能瓶颈出现，可以用合适的 GPU/Canvas 策略优化，但不牺牲数字和图表的正确含义。
- 交付源码、渲染命令、视频、几张关键画面截图和简洁的实现解释。明确记录实际已验证的内容，而不是仅说「已经完成」。

## 特别注意数据真实性

M1使用 `data/m1_hero_scene_2027.json`，由 `2027_position_derived_aggregates.json` 的410个省份×第三方系统标签单元生成，共19,426职位记录、35,691名额。以此计算税务24,013和余量11,678，不混用HTML另一套28类归集。

粒子用“单元键+序号”保持确定性，代表聚合计数，不是官方岗位ID。地区与系统可按联合单元迁移；机构层级、学历、考试类别和跨年份没有相同的完整联合表，必须重建场景，不能宣称同一个岗位在任意维度间迁移。

649是第三方抽取的代码词元，**已发现学历目录碰撞与TK尾缀截断**，详见专业审计。0809不能统一贴“计算机类”，0812不能统一贴“计算机科学与技术”，name_hints不是标准目录名称。

030101K对应316条记录/385名额，可用于独立词元探索；字幕为“第三方清洗字段词元提及 · 非全部可报岗位”。不能跨代码相加或推测交并集，结果停在聚合卡。真实专业→具体职位仍需原文、学历分句、目录版本及行ID重建。

官方移民管理机构1,089名额数据可用于独立机构镜头；其22个总站1,020与其余机构69的关系来自官方公告，但并未据此核验全国所有职位。不要把它与第三方immigration标签134人直接替换。

全国官方原始文件尚未独立取得并逐行对照。数值加总和内容卡通过校验不等于来源真实性、专业语义或资格审核全部通过。

## 艺术方向

沿用或升级原网页的克制暗色系、珊瑚橙、鼠尾草绿、灰蓝点缀，建议参考高端科技发布片和顶尖 Motion Design 的精确感，而不是廉价 HUD。构图、层次、空间、节奏比镜头数量重要。时刻问自己：

- 这一帧是否有清晰的信息焦点？
- 这个动效是否由数据含义自然推导？
- 停在任一关键帧，画面是否仍具有高级美感？
- 每次变化是否值得观众看，而不只是让 GPU 忙碌？
