# 2027 国考数据调研与来源核验

**调研日期：2026-10-17。**

## 核心更新

此前「2027 年逐岗位数据尚未提供」仅指**用户参考 HTML 自身只有 28 类汇总**。截至 2026-10-17，国家公务员局的**2027 年正式公告与招考简章已于 2026-10-13 发布**。不能再把「官方还没发布」作为专业筛选的障碍；真正障碍是**原始职位表尚未在本项目完成直接官方文件同源核验和专业资格规则建模**。

## A. 官方优先来源

1. 国家公务员局 2027 年专题网站：<http://bm.scs.gov.cn/kl2027>。公告明确指出招考简章、职位条件、报考指南在专题网站公布。本站需从浏览器「相关下载」取得原始 XLS/ZIP；当前研究环境无法直接成功下载该站的原始附件，尚不能出具原始文件 SHA256。
2. **2027 公告原文**（国家公务员局，新华网 2026-10-13 转载）：https://www.xinhuanet.com/edu/20261013/ce6bf7dc36474dd68ecd90aa8b722f06/c.html
   - 注册实名认证 10/14 08:00—10/23 18:00；申请报名 10/15 08:00—10/24 18:00；公共科目笔试 11/29。
   - 一般年龄 18–38 岁，2027 年应届硕博放宽到 43 岁；具体条件以原公告为准。
3. 国家税务总局广东省税务局《税务系统2027年度考试录用公务员相关事项通知》（2026-10-15）：https://guangdong.chinatax.gov.cn/gdsw/ryzl/2026-10/15/content_84db51dbef8a460c93d9f0064edece05.shtml
   - 2027 税务职位有**专用专业参考目录**；不可单纯靠专业关键词推定资格。
   - 专业与最高学历对应，且学历、学位、备注、专业类别有细化约束。
4. 教育部《普通高等学校本科专业目录（2026年）》：https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/t20260427_1434931.html
5. 教育部《研究生教育学科专业目录（2022年）》：https://www.moe.gov.cn/srcsite/A22/moe_833/202209/t20220914_660828.html
6. 教育部《关于教育部2027年度公务员考录职位要求的说明》：https://www.moe.gov.cn/s78/A04/tongzhi/202610/t20261014_1454189.html
   - 明确区分按学科门类、一级学科、二级学科的招聘专业范围，并说明特殊专业需要材料补充确认。

数据的四种不同验证概念，不可混淆：

- **官方公告核验：** 公告、专业目录与笔试时间可以从政府来源直接确认。
- **全量数值核验：** 第三方清洗的 19,426 行可以编程加总到 35,691 人，且 31 地区与另一来源完全一致。
- **原始文件真伪校验：** 尚未从国家公务员局官方专题下载源文件并计算 SHA256；**未完成**。
- **业务匹配正确性：** 专业代码与某一考生真实报考条件的对应关系尚未完成，必须另行建模和逐岗位核验。

## C. 内容统计可怎么说

- 可以说：「2027 年国考招考简章公开的职位表经第三方整理为 **19,426 个职位、35,691 个招录名额**」。
- 可以说：「根据本项目来源一致的汇总，税务系统 **24,013 人，占 67.3%**；排除税务还有 **11,678 人**」，同时标注统计是对聚合数据的分析。
- 可以说：「华图教育 2026-10-16 的省级统计显示广东 2,969 人、山东 2,316 人、云南 1,925 人；本项目对第三方清洗岗位表聚合得到相同结果」。
- 可以说：「2026—2027 年全国名额由 38,119 降至 35,691，减少 2,428（约 -6.4%）」，并标注是历史第三方对照表。
- **不能说：「某个专业代码必然可报 X 个职位」**，目前的专业码数据只支持「第三方预处理字段显式提到这个代码的职位 X 条」。
- 不输出岗位成功率、录取概率、真实待遇、所谓「最容易上岸」或假冒官方专业匹配结论。
