# 专业代码联动：从视觉技术 Demo 到真实候选职位的计算边界

## 核心结论

现在确实已有 **649 个可被提取的专业代码**，并生成了专业代码 → 省份 → 第三方系统标签的关系网。它足以做「选一个代码，关联系统与地图逐层点亮」的确定性动画。

**但**这是「代码在职位表清洗字段中被显式提及」的关系，不是「该专业考生可报考该职位」的判定。全量岗位 19,426 条中，仅 3,252 条包含至少一个被清洗器识别的显式代码；剩余的许多专业条件是名称、类别、泛化表述或学历层次规则，不可被误判为没有岗位。

## 两阶段产品语义

### 阶段 P0：可立即用于视频的「显式提及图谱」

输入源：data/2027_position_derived_aggregates.json → major_code_mentions.codes 数组。

用户选择一个 code 后，可读取：

- code / name_hints
- explicit_mentions_positions（含该代码的**职位行数**）
- explicit_mentions_hires（这些职位对应的**招录人数**）
- by_province（地区分布）
- by_source_system_tag（第三方分析标签分布）
- by_province_and_source_system_tag（跨地区和系统的真实交叉关系）
- by_agency_class（官方四大机构类型的第三方解析结果）

所有数值基于同一组职位行，能做真实面积、粒子、流线与图表联动；各省份、系统标签汇总分别加回所选代码父节点。不要把一个代码的多个地区与系统数据相乘。

**画面应标注：** 「招考简章专业字段显式代码匹配 · 仅示例性职位提及统计，非完整报考资格判断」。

### 阶段 P1：可解释的「真实候选职位过滤」——尚未实现

需要保留完整逐条职位源（不一定公开上传），逐岗位处理：

1. 本科目录与研究生目录独立，专业代码的门类/大类/具体专业层级不等价。
2. 字符串有「本科：……；研究生：……」「限某层次」「目录中某大类」等组合，必须先按学历路径区分后才能匹配。
3. 很多岗位只写「经济学类、金融学类、计算机类」「不限专业」等文字，即使没有显式代码，也可能匹配。
4. 税务系统 **2027 年专业参考目录**有独立映射，同名专业可能横跨不同目录类别（如经济统计学同时在经济学与统计学中），不能套通用前缀规则。
5. 职位备注可能进一步限定性别、应届身份、专业方向、英语等级、工作经验、户籍、服务年限等；不能靠专业一个维度输出「可报」。
6. 特殊专业、新专业、境外学历认证与专业相近情况应归为「待招考机关确认」，而非擅自通过/否决。

## 前缀与代码碰撞风险

- 「0809 计算机类」是大类标签，不等于每个「080901 计算机科学与技术」的具体匹配都被清洗 CSV 显式提及。
- 「0301 法学类」与「030101K 法学」需区分大类/具体专业的代码层级；专业名称与专业代码不应互为简单前缀匹配。
- 代码末尾字母 K/T 等是专业代码组成部分，不能机械剔除。
- 同一岗位可能列举多个专业代码，跨代码职位汇总可重叠，**严禁把 649 个代码的职位数相加作为全国职位数**。
- 源字段 major_codes 由第三方项目生成，部分中文标签可能只保留片段；UI 应以确认过的官方目录名称为主，无法确认的只展示代码。

## 为 Opus 设计的最有潜力的镜头

**INPUT / 030101K / 法学（专业代码示例）**

1. 0–2 秒：画面上出现 030101K，中心节点被锁定。
2. 2–4 秒：从同一 JSON 的 by_province_and_source_system_tag 单元生成真实关系边，不是随机流线。
3. 4–6 秒：全国节点低亮，只让显式提到该代码的关系子图渐亮。
4. 6–9 秒：地区节点根据职位行数/名额数伸缩，系统标签按一套固定颜色映射。
5. 9–12 秒：镜头进入其中一个具体地区的「地区×系统」交叉单元，说明「显式提及」口径。
6. 12–15 秒：复位全国全景，保留所有节点的相对关系。

这一阶段先实现专业代码被提及的**真实聚合关系可视化**，不要出现「你能报 X 岗位」「录取几率」等未经核验文案。

## 交付与验收测试

- 针对任意 code：按省份/系统/交叉单元分别求和，等于 explicit_mentions_positions 与 explicit_mentions_hires。
- 按同一筛选状态驱动标题、数字、图表、连线与相机焦点。
- 未匹配的专业代码要有合理的「数据覆盖不足」状态；**不等于 0 个可报岗位**。
- 所有帧由 Remotion frame 编号确定，鼠标录屏、实时 API、任意 setTimeout 不构成可复现的最终影片。
- 系统标签 source_system_tag 来自第三方分析，不是国家公务员局官方机构分类，应在字幕或来源说明中写明。
