## 新项目原则

新视频不要直接堆在仓库根目录。至少建立：

- `README.md`：项目目标、状态、交付物
- `CREATIVE_BRIEF.md`：创意、叙事、审美、取材
- `PRODUCTION_PLAN.md`：制作阶段与验收
- `reference/`：原始参考素材
- `remotion/`：需要代码时再建立

视频项目之间默认互不干扰。一个项目的技术实验可以沉淀为经验，但未经明确设计不强制抽象成全仓库共享框架。

## 状态标签

- `IDEA`：想法
- `PLANNED`：已立项
- `BUILDING`：制作中
- `REVIEW`：审片/验收
- `PUBLISHED`：已发布
- `ARCHIVED`：归档
